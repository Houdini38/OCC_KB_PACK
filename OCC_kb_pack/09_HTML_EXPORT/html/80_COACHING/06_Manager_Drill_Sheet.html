Manager Drill Sheet

Purpose

This document is for sales managers, trainers, and ride-along leaders running weekly sales meetings, team drills, or post-appointment debriefs.

The goal is controlled, consistent sales behavior across the team.

This file is manager-facing. It should not override rep-facing approved language, Step 8, Step 9, financing compliance, warranty rules, or product facts.

Coaching Philosophy

  1. Score process, not cleverness.
  2. Drill one step at a time.
  3. Tie every drill to a KPI.
  4. Use real photos and customer language from recent appointments.
  5. Reward clean process even if the drill does not close.
  6. Coach the upstream cause, not only the downstream objection.
  7. Protect margin and compliance before style.

Drill 1 - Step 1 Timer Drill

Element Detail
How to run it Rep opens the appointment and confirms time expectation.
Pass standard Agenda is clear, appointment length is confirmed, and rep does not jump into product or price.
Common failure Rep skips time confirmation or lets customer compress the process.
KPI moved Process Compliance / Close Rate
Coaching note Skipped Step 1 creates rushed Step 8s and surprise spouse objections later.

Drill 2 - Step 2 Urgency Drill

Element Detail
How to run it Use real inspection photos. Rep gets customer to own the problem.
Pass standard Customer agrees the issue is real, worsening, and worth addressing.
Common failure Rep points out defects but does not create emotional ownership.
KPI moved Same-Day Close Rate
Coaching note If urgency is weak, final objections multiply.

Drill 3 - Step 3 Challenger Drill

Element Detail
How to run it Rep teaches DIY, contractor, and SuperiorPRO using one real home scenario.
Pass standard Rep teaches, tailors, and differentiates without competitor-bashing.
Common failure Generic company story or negative competitor claims.
KPI moved Close Rate / Shopping Resistance
Coaching note Listen for unsupported warranty, ranking, or competitor claims.

Drill 4 - Step 4 Investment Drill

Element Detail
How to run it Rep explains cost versus value without giving price.
Pass standard Uses investment language and earns agreement before demo.
Common failure Rep reveals price too early or apologizes for premium position.
KPI moved Average Ticket / Margin
Coaching note Weak Step 4 shows up as discount pressure in Step 8.

Drill 5 - Step 5 Complete Project Drill

Element Detail
How to run it Rep explains materials, prep, labor, installation, cleanup, and warranty boundaries for a specific home.
Pass standard Customer can repeat why the full project matters.
Common failure Rep shows samples without explaining the complete project.
KPI moved Average Ticket / Same-Day Close
Coaching note Product docs teach value. Warranty docs control warranty.

Drill 6 - Step 6 Isolation Drill

Element Detail
How to run it Rep delivers Pre-Close and isolates anything besides investment.
Pass standard Rep asks the approved isolation question clearly before price.
Common failure Rep skips isolation because the appointment feels good.
KPI moved Same-Day Close Rate
Coaching note This is the highest-leverage habit in the system.

Drill 7 - Step 8 Approved Sequence Drill

Element Detail
How to run it Customer reacts to price. Rep must run Step 8 in approved order.
Pass standard List Price, high starting payment, monthly isolation, confirmation, trial close, Monthly Promotion, then Add/Subtract/Sharp Angle only if needed.
Common failure Promotion offered before monthly number, or Add/Subtract/Sharp Angle used too early.
KPI moved Financing Attachment / Margin
Coaching note Payment isolation first. Promotion second. Compliance always.

Drill 8 - Step 9 Approved Close Drill

Element Detail
How to run it Rep practices physical disarm, timeline question, WOW line, Promo Home / Marketing Opportunity, adjusted offer, direct close.
Pass standard No skipped step, no fake manager authority, no Step 8 language drift.
Common failure Rep skips physical disarm or presents offer without justification.
KPI moved Same-Day Close / Margin
Coaching note The offer must be justified every time. Do not use retired terms like First Drop or Last Drop.

Drill 9 - Final Objection Drill

Element Detail
How to run it Manager gives one common final objection. Rep must diagnose, isolate, respond, and close back.
Pass standard Rep isolates the real barrier and asks for decision or defined next step.
Common failure Rep gives a generic answer without upstream diagnosis.
KPI moved Same-Day Close / Rehash Close Rate
Coaching note Use 80_COACHING/04_Upstream_Diagnosis.md before drilling the script.

Drill 10 - Follow-Up Call Drill

Element Detail
How to run it Rep calls a no-sale customer. Manager plays customer.
Pass standard Rep reopens professionally, references appointment, isolates current blocker, reconnects to original problem, and asks for decision or scheduled next action.
Common failure Rep says "just checking in" and waits.
KPI moved Rehash Close Rate
Coaching note Follow-up calls are flexible language, but outcome-based.

30-Minute Sales Meeting Template

Time Activity
0:00-0:05 Frame the issue and the KPI it moves. Use a real field example.
0:05-0:10 Show risky old language versus approved language.
0:10-0:20 Pair roleplay. One rep is customer, one rep runs the drill.
0:20-0:25 KPI tie-back. Each rep states what KPI the drill moves and why.
0:25-0:30 Commitment. Each rep chooses one Hope drill to complete this week.

Manager Debrief Questions

Use these after ride-alongs, transcript reviews, or missed-sale reviews:

  1. Did the rep follow the 10-step sequence?
  2. Did the customer emotionally own the problem in Step 2?
  3. Did the rep price-condition before price?
  4. Did the rep run the Step 6 isolation question?
  5. Did the rep deliver the approved Step 8 sequence?
  6. Did the rep use approved Step 9 sequence and direct close?
  7. Did the rep stay compliant on financing, warranty, product, and ROI claims?
  8. If no sale, did the rep leave with a defined next step?
  9. Did the rep complete the Warm Down after a yes?
  10. What is the single behavior this rep should drill with Hope this week?

What Managers Should Reward

  • Process compliance over closing theater
  • Defined next steps over vague follow-up
  • Margin protection over discount creativity
  • Customer-specific language over generic delivery
  • Correct financing compliance even when it slows the rep down
  • Strong Warm Down after a yes

What Managers Should Penalize

  • Skipping Step 6 isolation
  • Reordering Step 8 or Step 9
  • Inventing financing terms, warranty coverage, product specs, ROI, or manager authority
  • Stacking discounts
  • Skipping Warm Down
  • Using retired terms like First Drop or Last Drop
  • Saying "free financing" or implying guaranteed approval

Final Rule

Managers should observe the downstream symptom, then coach the upstream cause.

That is how coaching moves revenue instead of creating prettier scripts.
