# Phase 5 Audit - Warranties

## Purpose

This audit controls the warranty folder before ElevenLabs HTML conversion.

The warranty lane should be simple, rep-friendly, and low-interruption. Reps are not expected to recite legal warranty language from memory. They should give clear, honest explanations and direct customers to the written warranty documents.

## Current Source Files Provided

The current warranty source set consists of:

```text
00_WarrantyOverview.md
01_WarrantyByProduct.md
```

These are being converted into the `06_WARRANTIES` folder as clean Markdown source files.

## Coaching Philosophy

Warranty coaching should be simple.

Do not interrupt reps constantly for minor wording differences.

Use soft correction unless the rep makes a clear overpromise.

## Hard Correction Triggers

Hope should correct immediately if the rep says or implies:

- Everything is covered.
- It is covered forever.
- SuperiorPRO provides 30-year workmanship.
- Lifetime warranty when the manufacturer does not specifically warrant it for life.
- Manufacturer approval is guaranteed.
- Labor is covered by SuperiorPRO for the full manufacturer warranty period without manufacturer approval.
- Warranty terms not found in the KB.

## Soft Coaching Triggers

Use soft coaching after the attempt if the rep:

- Explains the warranty unclearly.
- Forgets to separate SuperiorPRO workmanship from manufacturer coverage.
- Forgets to offer the written warranty document.
- Forgets to mention exclusions when relevant.
- Uses too much legal language and confuses the customer.

## Replacement Strategy

Expected KB folder structure:

```text
06_WARRANTIES/
  01_Company_Workmanship_Warranty.md
  02_Manufacturer_Warranties.md
  03_Warranty_Comparison_FAQ.md
  04_Warranty_Claim_Limits.md
```

## Authority Rules

1. Written warranty documents and signed contract are the final word.
2. Warranty by Product controls product-specific warranty statements.
3. Warranty Overview controls general warranty philosophy.
4. Hope should simplify, not overcomplicate.
5. If warranty information is not confirmed, use the safe default answer.

## Safe Default Answer

Use this anytime the rep is unsure:

> SuperiorPRO warranties vary by product. We cover installation issues for 24 months on most jobs. Some products also have longer manufacturer coverage where we help with labor if the manufacturer approves. Your signed contract and warranty document are the final word.

## Completion Gates

Before HTML export, warranty files must pass these gates:

- The 24-month SuperiorPRO installation/workmanship rule is clear.
- Manufacturer coverage is separated from SuperiorPRO workmanship.
- Labor help is tied to manufacturer approval where applicable.
- Product-specific warranty terms match the warranty by product file.
- Exclusions are clear but not overdone.
- Hope's coaching behavior is low-interruption except for overpromises.

## Revenue Rule

Warranty should build trust, not create confusion.

Simple, honest, product-specific explanations help close rate without turning the appointment into a legal seminar.
